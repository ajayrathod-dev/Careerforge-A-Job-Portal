# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within CareerForge, please do not disclose it publicly in issues or discussions.

Instead, please report security concerns directly to the project maintainer:
- **Email**: mr.developer9607@gmail.com
- Subject line: `[Security] CareerForge Vulnerability Report`

### What to Include in Your Report:
- A description of the vulnerability.
- Steps to reproduce or proof-of-concept (PoC).
- Potential impact and scope.
- Suggested mitigations (if known).

We will acknowledge receipt within 48 hours and work towards resolving the issue promptly.
